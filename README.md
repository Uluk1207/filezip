# FileZip — Веб-приложение для сжатия файлов
### Дипломная работа: «Создание веб-приложения для сжатия и оптимизации документов и медиафайлов»

---

## Структура проекта

```
FileZip/
├── index.html          — Главная страница
├── compress.html       — Страница сжатия файлов
├── tools.html          — Дополнительные инструменты
├── history.html        — История обработок
├── about.html          — О проекте
│
├── css/
│   ├── style.css       — Основные стили (темная тема, компоненты)
│   ├── compress.css    — Стили страниц сжатия и инструментов
│   └── responsive.css  — Адаптивная верстка (мобильные устройства)
│
└── js/
    ├── app.js          — Общие утилиты (toast, history, formatBytes)
    ├── compress.js     — Логика страницы сжатия (drag&drop, dispatch)
    ├── image.js        — Сжатие и обработка изображений (Canvas API)
    ├── document.js     — Работа с PDF (pdf-lib: merge, split, watermark...)
    └── history.js      — Страница истории (LocalStorage)
```

---

## Запуск

Откройте `index.html` в любом современном браузере.

> ⚠️ Для корректной работы библиотек (pdf-lib через CDN) требуется подключение к интернету при первом открытии.
> Для офлайн-работы скачайте библиотеки в папку `libs/` и измените пути в HTML.

## Функции

### Сжатие (compress.html)
| Формат | Метод | Уровни |
|--------|-------|--------|
| PDF | pdf-lib (пересборка) | Высокое / Среднее / Низкое |
| JPG/PNG/WEBP | Canvas API | Регулируемое качество 10–100% |
| TXT/CSV | Нормализация пробелов | Авто |
| DOC/DOCX/XLS/PPTX | Структурная оптимизация | Высокое / Среднее / Низкое |

**Отображение результатов:** исходный размер, размер после сжатия, % экономии, время обработки.

### Инструменты PDF (tools.html)
- ✚ **Объединить PDF** — слияние нескольких PDF в один
- ✂ **Разделить PDF** — извлечение диапазона страниц
- ↻ **Повернуть страницы** — 90° / 180° / 270°
- ◈ **Водяной знак** — текст с настройкой прозрачности и цвета
- 🔒 **Защита PDF** — установка пароля (метаданные)
- ⇄ **Конвертация** — PDF/TXT → TXT/CSV

### Инструменты изображений (tools.html)
- ⊞ **Изменить размер** — по ширине/высоте с сохранением пропорций
- ⊡ **Обрезка** — по координатам X, Y, W, H
- ↺ **Повернуть** — 90° / 180° / 270°
- 🔄 **Конвертация** — JPG ↔ PNG ↔ WEBP

### История (history.html)
- Хранится в **LocalStorage** браузера
- Статистика: файлов, сэкономлено, среднее сжатие
- Фильтр по типам: PDF / Изображения / Другие
- Очистка истории

## Технологии

| Технология | Назначение |
|-----------|-----------|
| HTML5 | Разметка, File API, Drag & Drop API |
| CSS3 | Темная тема, анимации, адаптивность |
| Vanilla JavaScript | Вся логика без фреймворков |
| pdf-lib 1.17 (CDN) | Работа с PDF в браузере |
| FileSaver.js (CDN) | Скачивание файлов |
| Canvas API | Сжатие и обработка изображений |
| LocalStorage | Хранение истории операций |

---

## Поддерживаемые форматы

**Документы:** PDF, DOC, DOCX, PPT, PPTX, XLS, XLSX, TXT, CSV, ZIP  
**Изображения:** JPG, JPEG, PNG, WEBP

---

## Конфиденциальность

Все операции выполняются **исключительно в браузере**. Файлы не загружаются на серверы.
