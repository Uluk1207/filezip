О проекте

Дипломная работа — веб-приложение для сжатия и оптимизации файлов

📋 Описание проекта

СжатьФайл — клиентское веб-приложение для сжатия, оптимизации и обработки документов и медиафайлов. Приложение разработано как аналог сервисов iLovePDF и SmallPDF, но работающий полностью в браузере пользователя без серверной части и без загрузки файлов на сторонние серверы.

Все операции по сжатию, конвертации и обработке файлов выполняются локально с использованием возможностей современных браузеров и JavaScript-библиотек.

🎯 Цель и задачи

  • Разработать современный пользовательский интерфейс в стиле iLovePDF
  • Реализовать сжатие PDF-документов с помощью pdf-lib
  • Реализовать сжатие изображений (JPG, PNG, WEBP) через Canvas API
  • Добавить инструменты для работы с PDF: объединение, разделение, поворот, водяной знак
  • Добавить инструменты для изображений: изменение размера, обрезка, конвертация, поворот
  • Сохранять историю операций в LocalStorage
  • Обеспечить полную работоспособность без сервера

🛠 Технологии

Стек разработки — только клиентские технологии:

HTML5 CSS3 Vanilla JavaScript pdf-lib 1.17 FileSaver.js Canvas API File API LocalStorage Drag & Drop API Blob API

📂 Поддерживаемые форматы

  • Документы: PDF, DOC, DOCX, PPT, PPTX, XLS, XLSX, TXT, CSV
  • Изображения: JPG, JPEG, PNG, WEBP
  • Архивы: ZIP

⚙️ Функции сжатия

  • PDF: Пересборка через pdf-lib с удалением метаданных и лишних объектов
  • Изображения: Сжатие через Canvas API с регулируемым качеством (10–100%)
  • Документы DOC/DOCX: Оптимизация структуры ZIP-архива
  • Три режима: Высокое (70–80%), Среднее (50–60%), Низкое (20–30%)

🔐 Конфиденциальность

СжатьФайл не загружает ваши файлы на серверы. Все операции выполняются исключительно в вашем браузере. История хранится в LocalStorage вашего устройства и может быть очищена в любой момент. Ваши файлы никогда не покидают ваш компьютер.

📈 Анализ аналогов

  • iLovePDF — серверная обработка, платные функции, загрузка файлов на серверы
  • SmallPDF — лимиты на бесплатных аккаунтах, требует регистрации
  • СжатьФайл — полностью клиентский, бесплатный, приватный, без ограничений
